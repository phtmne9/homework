# Урок 10. Обработка видео и FastAPI

## Про задание

К теме в MyStat приложен только архив с материалами урока — четыре примера:
чтение видео, извлечение кадров, обработка видео и детекция движения. Текста
домашнего задания нет. Объём работы определён по этим материалам и названию темы:
те же четыре операции оформлены как переиспользуемый модуль и подняты сервисом
FastAPI.

Исходное видео к уроку тоже не приложено, поэтому тестовый ролик генерируется
скриптом `make_video.py`.

## Состав

| Файл | Назначение |
|---|---|
| `make_video.py` | Генерирует `sample.mp4`: 120 кадров, 20 fps, движущиеся объекты |
| `video_tools.py` | Четыре операции: `video_info`, `extract_frames`, `process_edges`, `detect_motion` |
| `urok10_video.ipynb` | Демонстрация всех операций с кадрами и графиком |
| `api.py` | FastAPI поверх `video_tools` |

## Запуск

```
python make_video.py
uvicorn api:app --reload
```

Документация: `http://127.0.0.1:8000/docs`

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/health` | Проверка работоспособности |
| POST | `/info` | Характеристики видео: fps, размер, число кадров, длительность |
| POST | `/frames?every=30` | Извлекает каждый N-й кадр |
| POST | `/edges` | Возвращает видео с выделенными границами |
| POST | `/motion?min_area=600` | Детекция движения, список событий по кадрам |

Пример:

```
curl -X POST http://127.0.0.1:8000/info -F "file=@sample.mp4"
```

## Ограничения загрузки

Принимаются только `.mp4`, `.avi`, `.mov`, `.mkv` размером до 50 МБ. Расширение
проверяется до обработки, файл кладётся во временный каталог — пользовательское имя
в пути не используется, чтобы нельзя было выйти за его пределы.

## Замечание про MOG2

Алгоритму вычитания фона нужно несколько десятков кадров, чтобы построить модель
неподвижной сцены. В первых кадрах он отмечает как движение почти всё, поэтому
превью с рамками берётся после тридцатого кадра.
