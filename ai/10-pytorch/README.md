# Урок 10. Нейроны, нейронная сеть и PyTorch

Датасет Iris: 4 признака, 3 класса. Закрыты все три уровня домашней работы.

| Уровень | Что сделано | Где |
|---|---|---|
| Лёгкий | Обучение при epochs 50, 100, 200, сравнение loss и accuracy | `urok10.ipynb` |
| Средний | Три архитектуры: 4-8-3, 4-16-8-3, 4-32-16-8-3, таблица accuracy | `urok10.ipynb` |
| Сильный | `POST /predict` на FastAPI, модель и scaler сохранены и переиспользуются | `api.py` |

## Запуск API

```
uvicorn api:app --reload
```

Документация: `http://127.0.0.1:8000/docs`

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/` | Информация о модели, признаках и классах |
| GET | `/health` | Проверка, что модель загружена |
| POST | `/predict` | Принимает 4 признака, возвращает `class_id`, `class_name`, `probabilities` |

Пример запроса:

```
curl -X POST http://127.0.0.1:8000/predict \
  -H "Content-Type: application/json" \
  -d '{"features":[5.1,3.5,1.4,0.2]}'
```

Ответ:

```json
{"class_id":0,"class_name":"setosa","probabilities":{"setosa":1.0,"versicolor":0.0,"virginica":0.0}}
```

## Артефакты

`model.pt` хранит веса, архитектуру, имена классов и признаков. `scaler.pkl` —
обученный StandardScaler. API обязательно применяет тот же scaler, что и при
обучении: без него признаки придут в другом масштабе и предсказание будет мусором.

## Замечание про Softmax

В модели Softmax отсутствует намеренно. Сеть возвращает logits, а `CrossEntropyLoss`
применяет log-softmax внутри себя. Если добавить Softmax в `forward`, нормировка
произойдёт дважды и градиенты исказятся. Softmax применяется только при выводе
вероятностей — в ноутбуке и в API.
